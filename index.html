Gold Box Web

Plays your own copy of Pool of Radiance in the browser, in 3D.

Point this at the folder holding a game you own — the one with POOL.CFG and the .DAX files in it. The files are read in this browser tab and never uploaded anywhere. No game data ships with this app.

…or drop the folder here.
